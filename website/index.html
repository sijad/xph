01 / THE IDEA

A component workflow.
A PHP deployment.

Keep your request-time logic in PHP. Give your templates explicit contracts, reusable components, and a dedicated build step.

{ }

Contracts that carry through

Declare Props and Server with TypeScript. Both contracts are validated at runtime, including arguments and results of declared server methods.

</>

One component, together

Compose imported components and default slots. Write scoped CSS and browser TypeScript alongside your template; the build bundles them into hashed assets.

Deploy what PHP needs

Ship the generated PHP runtime, components, and static assets. Your production server needs PHP 8.2+; Node.js stays in development.

02 / GET STARTED

From template to response.

Use Node.js 22.12+ for development and PHP 8.2+ to check and render your components.

01

Try the working example

The repository includes a complete example. Install the pinned pnpm version through Corepack, then build the compiler and application.

Terminal 
git clone https://github.com/sijad/xph.git
cd xph
corepack pnpm install
corepack pnpm build
corepack pnpm --filter xph-example-basic build
corepack pnpm --filter xph-example-basic preview

Open http://localhost:8080

02

Define your build

Create a component such as src/Welcome.xph using the syntax above. Choose your entry points and output directory in xph.config.ts.

Run xph build with the CLI on your path. Use xph check to check contracts and PHP syntax, or xph dev to watch changes.

xph.config.ts 
export default {
  entries: ['src/Welcome.xph'],
  outDir: 'dist',
  assetBase: '/assets/',
  php: 'php',
};
03

Render from PHP

Load the generated entry point and render a component with its props. Use \Xph\assets() to get its CSS and JavaScript URLs and emit the tags where your application needs them.

Copy the generated directory to your PHP server, including its static assets.

Your PHP application 
<?php
require __DIR__ . '/dist/xph.php';

echo \Xph\render('src/Welcome', [
    'name' => 'world',
]);

$assets = \Xph\assets('src/Welcome');
