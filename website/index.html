MORE WAYS TO COMPOSE

Familiar syntax, compiled for PHP.

Use expressive templates while keeping request-time computation in native PHP.

Classes and attribute spreads

Combine class:list strings, nested arrays, and conditional object keys. Spread HTML attributes or component props; later values override earlier ones.

Template 
---
import Card from './Card.xph';
export interface Props { active: boolean; title: string }
---
<section class:list={['panel', { active: props.active }]}>
  <Card {...props} title="Welcome" />
</section>

Dynamic HTML elements

Choose an HTML tag with a string binding. Dynamic elements support ordinary attributes and scoped styles, including inside template expressions.

Template 
---
export interface Props { title: string }
const Tag = 'section';
---
<Tag aria-label="Welcome">
  <h2 set:text={props.title} />
</Tag>

01 / GETTING STARTED

Getting started with xph.

Use Node.js 22.12+ for development and PHP to check and render your components.

01

Install xph

Create a project and install xph from npm as a development dependency.

Terminal 
mkdir my-xph-app
cd my-xph-app
npm init -y
npm install -D xph
mkdir src
02

Write your first component

Create src/Welcome.xph in your new project.

Declare the props your component accepts and the data PHP returns. Use that data in your template; xph escapes dynamic text and scopes your styles.

src/Welcome.xph 
---
export interface Props {
	name: string;
}

export interface Server {
	greeting: string;
}
---

<script server lang="php">
  return [
    'greeting' => 'Hello, ' . $props['name'],
  ];
</script>

<h1>{server.greeting}</h1>

<style>
	h1 {
		color: olive;
	}
</style>
03

Define your build

Create xph.config.ts in your project root to choose your entry points and output directory.

From your project root, run npx xph check to check contracts and PHP syntax, then npx xph build to generate PHP and assets. Use npx xph dev to rebuild as you edit.

xph.config.ts 
export default {
	entries: ['src/Welcome.xph'],
	outDir: 'dist',
	assetBase: '/assets/',
	php: 'php',
};
04

Render from PHP

Create dist/index.php with the following code. Load the generated entry point and render your component with its props. Use \Xph\assets() to get its CSS and JavaScript URLs and emit the tags where your application needs them.

Run php -S localhost:8080 -t dist from your project root and open http://localhost:8080 to see “Hello, world”. Copy dist/ to your PHP server to deploy.

dist/index.php 
<?php
require __DIR__ . '/xph.php';

foreach (\Xph\assets('src/Welcome') as $asset) {
    if ($asset['type'] === 'css') {
        echo '<link rel="stylesheet" href="'
            . htmlspecialchars($asset['url'], ENT_QUOTES, 'UTF-8') . '">';
    }
}

echo \Xph\render('src/Welcome', ['name' => 'world']);
